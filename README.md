# Pandas bibliotēkas analīze

## Projekta apraksts

Šajā projektā tiek analizēta Python bibliotēka Pandas.

Tiek demonstrētas 15 populārākās funkcijas ar praktiskiem piemēriem.

---

# Izmantotās tehnoloģijas

- Python
- Pandas
- Git
- GitHub
- Visual Studio Code

---
# Bibliotēkas izvēles pamatojums

Pandas tika izvēlēta, jo tā ir viena no populārākajām datu analīzes bibliotēkām.

---

# Demonstrētās funkcijas

1. DataFrame()
2. read_csv()
3. head()
4. tail()
5. Filtrēšana
6. mean()
7. max()
8. min()
9. sort_values()
10. isnull()
11. drop_duplicates()
12. describe()

# Secinājumi

Pandas ir ļoti noderīga datu apstrādes bibliotēka.

Galvenie ieguvumi:

- Vienkārša sintakse
- Ātra datu apstrāde
- Daudz funkciju
- Plašs pielietojums industrijā
Ierobežojumi:

- Lieliem datiem nepieciešama daudz RAM
- Dažas funkcijas ir sarežģītas iesācējiem
